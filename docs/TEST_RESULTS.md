### 점검 중 발견해 고친 문제
1. 첫 실행 시 설정 기본값을 읽기 전용 쿼리 안에서 저장하려다 오류 → 시작 시 한 번 만들도록 수정.
2. 1일 차에 “계획보다 6개 늦어요”로 표시(오늘 분량을 밀린 것으로 계산) → 어제까지 기준으로 수정.
3. 시대(구석기 vs 신석기) 혼동이 “인물 혼동”으로 분류 → 시대 혼동으로 수정, “비슷한 사건·단체·나라 혼동” 원인 추가.
4. 소개만 하고 아직 일정이 잡히지 않은 개념이 기억 유지 추정치를 0%로 끌어내림 → 일정이 잡힌 개념만 평균.
5. 묶음 개념(예: 보안회와 대한 자강회)에서 자료의 주체와 정답의 주체가 다른 잘못된 문제가 생성될 수 있음 → 자료형 문제에서 제외 + 테스트 추가.
6. 정인보가 “사회 경제 사학과 실증 사학” 개념에 잘못 묶여 있음(정인보는 민족주의 사학·조선학 운동) → 백남운·정인보·진단 학회 세 개념으로 분리.
7. FSRS 퍼즈로 최대 간격을 하루 넘는 경우 → 앱에서 다시 제한.

## 3. 아직 검증하지 못한 것
- 실제 휴대폰(iOS Safari·Android Chrome)에서 홈 화면 설치·오프라인 사용 — 배포(HTTPS) 후 확인 필요.
- 기출 자동 태그의 전수 검수 — 표본 2개 회차(80회·67회)만 사람이 검수(단원 일치 88~96%, 개념 일치 약 76~87%).
- 실제 문제지 PDF를 휴대폰 화면에서 읽을 때의 가독성 — 2단 A4라 손가락으로 확대해야 함.
- 여러 날에 걸친 실제 사용(복습 간격, 밀린 날 재배분)의 체감 — 날짜를 바꾼 단위 테스트로만 확인.
- 302개 개념의 역사적 정확성 — 사실 1,022개 모두 출처(백과사전 + 우리역사넷)와 대조. 핵심어만 맞은 약한 자동 확인 279개는 사람이 모두 읽었고, 사람 확인은 모두 448개. 나머지 자동 확인 574개는 “핵심어와 나머지 내용이 같은 문장 근처에 있음”까지만 본 것(표본 30개는 모두 맞았으나 4개는 세부가 다른 문장·다른 출처에 있었음). 문제 문장·오답 선택지·설명문 전수 검수와 현행 검정 교과서 대조는 안 함.
