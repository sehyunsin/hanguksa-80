# 한국사 80 — 한국사능력검정시험 심화 3급 대비 개인 학습 PWA

매일 80분, “오늘의 학습” 버튼 하나로 진행하는 듀오링고식 반복 학습 앱입니다. 개인 1인용이며 회원가입·서버가 없습니다. 학습 기록은 기기 안(IndexedDB)에만 저장됩니다.

**앱 주소(GitHub Pages): https://sehyunsin.github.io/hanguksa-80/** — 휴대폰 브라우저로 열고 홈 화면에 추가하세요.

## 실행

필요: Node.js 22 이상.

```powershell
npm install
```

> 이 PC의 사용자 npm 설정(`~/.npmrc`)에 `os=linux`가 들어 있어 Windows용 네이티브 모듈이 빠질 수 있습니다. 그 경우 다음처럼 설치하세요(전역 설정은 바꾸지 않음).
>
> ```powershell
> npm install --os=win32 --cpu=x64
> ```

```powershell
npm run dev
```

- 개발 서버: http://localhost:5173 — 같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:5173`으로 열 수 있습니다(서비스 워커·설치는 HTTPS 배포본에서만 동작).
- 테스트: `npm test`
- 타입 검사: `npm run typecheck`
- 배포용 빌드: `npm run build` → `dist/`
- 빌드 결과 미리보기: `npm run preview`
- 커리큘럼 문서 재생성: `npm run docs`
- 기출 분석 다시 하기(PDF가 `exam-pdfs/`에 있을 때): `node scripts/extract-text.mjs exam-pdfs` → `powershell -ExecutionPolicy Bypass -File scripts/ocr-pdf.ps1 -Rounds "57,59,60"`(이미지형 회차) → `npx tsx scripts/analyze-exams.ts`

## 휴대폰에 설치(배포 가이드)

PWA 설치와 오프라인 동작에는 HTTPS 주소가 필요합니다. `dist/` 폴더는 정적 파일만 있으므로 아무 정적 호스팅에 올리면 됩니다. 경로는 상대 경로(`base: './'`)와 해시 라우팅이라 하위 경로에 올려도 동작합니다.

1. `npm run build`
2. 다음 중 하나로 `dist/`를 올립니다.
   - **Cloudflare Pages / Netlify**: 빌드 명령 `npm run build`, 출력 폴더 `dist`
   - **GitHub Pages**: `bash scripts/deploy-pages.sh`(빌드 후 `dist/`만 `gh-pages` 브랜치로 올림) → 저장소 Settings → Pages에서 `gh-pages` 브랜치 / (root) 선택. 콘텐츠를 고친 뒤에는 커밋하고 이 스크립트를 다시 실행하면 갱신됨(앱은 다음 실행 때 자동 업데이트)
3. 휴대폰 브라우저에서 주소를 연 뒤 “홈 화면에 추가”(iOS Safari: 공유 → 홈 화면에 추가 / Android Chrome: 메뉴 → 앱 설치).
4. 한 번 열면 모든 콘텐츠가 캐시되어 인터넷 없이도 학습할 수 있습니다.

> 학습 기록은 기기·브라우저별로 따로 저장됩니다(동기화 없음). 문제를 하나 풀 때마다 바로 저장되고, 앱을 업데이트해도 기록은 유지됩니다. iPhone은 Safari 탭과 홈 화면 앱의 저장소가 따로이므로 홈 화면 앱으로만 공부하세요. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 **설정 → 백업 파일 저장**을 하세요.

## 실제 기출 회차 등록 방법

1. 앱의 **실전 시험 → 공식 시험 자료실 열기**(https://www.historyexam.go.kr/pst/list.do?bbs=dat)에서 원하는 회차의 문제지 PDF와 답지 PDF를 직접 내려받습니다.
2. 회차 목록에서 **등록** → 문제지 PDF 선택 → 저장. 정답·배점은 앱에 들어 있는 공식 정답표로 자동으로 채워집니다(답지 PDF를 넣으면 다시 읽어 대조할 수도 있음).
3. **응시**를 누르면 80분 타이머와 답안지(OMR)로 실제처럼 풀고 공식 배점으로 채점합니다. 결과 화면에서 틀린 번호마다 자동 분석된 개념이 연결되어 바로 복습할 수 있습니다.
4. 최근 5개 회차(76~80회)는 기본으로 **실전 평가 전용**입니다. 첫 응시 성적만 “최종 준비 완료 기준” 판정에 쓰입니다.

## 콘텐츠 고치는 법

개념은 `src/content/units/uNN.ts`에 다음 형식으로 있습니다. 사실(fact) 하나가 여러 문제 유형의 재료가 됩니다.

```ts
{
  id: 'gr-gwangjong', name: '광종', kind: 'person', noun: '왕', when: '949~975 재위', sort: 949, tier: 'A',
  sum: '한 줄 요약', body: ['설명 문단'], keys: ['핵심 기억'],
  facts: ['[노비안검법]을 실시하였다'],   // [ ] = 빈칸 문제의 정답어, ~로 시작 = 일반적 서술(오답 선택지로 안 씀)
  cf: ['gr-seongjong'],                   // 헷갈리기 쉬운 개념
}
```

- 서로 다른 개념이 같은 내용을 공유하면(예: 태종·세조의 6조 직계제) 두 사실 끝에 같은 키 `{k:6조직계제}`를 붙여 서로의 오답 선택지가 되지 않게 합니다.
- 공식 자료와 대조를 마친 개념은 `status: 'verified'`로 바꿉니다.
- 수정 후 `npm test`로 무결성(없는 참조, 빈칸어 누락, 중복 키)과 문제 생성 규칙을 확인하세요.
