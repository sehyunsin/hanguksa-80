## 2. 기출문제 확보·분석(제57~80회 심화)

### 확보
- 2026-11-26, 사용자 허락을 받고 공식 자료실에서 **48개 PDF**(24개 회차 × 문제지·정답표, 약 332MB)를 내려받음. 파일은 `exam-pdfs/`에 있으며 **git과 앱 배포본에 포함하지 않음**(`.gitignore`).
- 재현: `scripts/download-ids.txt`(공식 첨부파일 ID) → `scripts/extract-text.mjs`(PDF 글자) / `scripts/ocr-pdf.ps1`(Windows 한국어 OCR) → `npx tsx scripts/analyze-exams.ts`.

### 글자 추출
| 회차 | 방법 |
|---|---|
| 58, 62, 70, 71, 72, 75, 76, 77, 80 (9개) | PDF 글자 레이어(pdf.js), 2단 편집 순서로 재정렬 |
| 57, 59, 60, 61, 63, 64, 65, 66, 67, 68, 69, 73, 74, 78, 79 (15개) | 글자 레이어가 없는 이미지 PDF → Windows 내장 OCR(한국어), 2단 순서로 정렬 |
| 정답표 24개 | 모두 글자 레이어. 형식 2가지(①~⑤ / 숫자) + 63회 42번 “없음”(정정, 전원 정답) |

### 분석 방법(자동)
1. 정답표 → 문항별 정답·배점(24개 회차 모두 50문항·합계 100점 검증 통과).
2. 문제지 → 문항 번호로 50개 문항 분할 → 발문·자료·선택지 분리.
3. 앱 개념 사전(개념 이름·핵심어·빈칸어)의 키워드를 **IDF 가중치**로 매칭. 자료 1.6배, 정답 선택지 1.4배, 나머지 선택지 0.35배. 문항 위치(대체로 시대순)와 문항 유형(‘지역’ 문항은 지역 개념 우대)을 약하게 반영.
4. 점수가 낮으면 태그를 붙이지 않음(추측 금지).
5. 집계: 개념별 “관련 문항이 나온 회차 수”(주 개념·관련 개념·정답 선택지 개념 포함), 단원별 주 개념 문항 수.

- 앱의 302개 개념 중 289개가 1회 이상 등장. 단원별 비중은 [CURRICULUM.md](CURRICULUM.md) 5절.

## 2-1. 개념 콘텐츠 대조(2026-11-27)

AI가 쓴 302개 개념(사실 1,022개)을 한국학중앙연구원 「한국민족문화대백과사전」 항목 **본문 서술**과 대조하고, 백과사전에서 근거를 찾지 못한 서술은 국사편찬위원회 **우리역사넷**(신편 한국사·역대 국사교과서·사료로 본 한국사·한국문화사)으로 확인했습니다.

### 방법
1. 개념마다 백과사전 검색(`/Article/Search?query=…`)으로 해당 항목을 고름(제목 일치 + 시대·키워드 조건, 개념별 검색어는 `scripts/verify-queries.json`). 항목 글자는 `verify-cache/`에만 저장(git·앱 배포본 제외).
   - 잘못 고른 항목 1건을 찾아 고침: ‘선종의 확산’이 고려 국왕 **선종** 항목에 연결돼 있었음 → 「선종구산문」·「불립문자」·「도의」로 교체. 비슷한 실수(왕 항목이 다른 개념에 붙음)가 더 있는지 302개 전부 훑어봄 — 나머지 12건은 왕 이름이 들어 있을 뿐 맞는 항목.
2. **본문 서술만** 사용: 항목 페이지의 관련 항목 목록·사진 설명·키워드 목록·참고문헌·주석은 뺌. (처음에는 페이지 전체를 썼는데, 참고문헌 책 제목 ‘서경문화사’가 ‘서경’으로, ‘초기철기시대’가 ‘철’로 잡히는 등 잘못된 확인이 표본에서 나와 고침.) 연대는 본문 + 정보 상자(출생·사망·재위 연도)에서 찾음.
3. 사실별 자동 확인(`scripts/verify_check.py`)
   - 핵심어(빈칸어, 2글자 이상)가 그 개념 항목 본문에 있음 → **자동 확인**(738개)
   - 핵심어 표기 차이(숫자 표기 등)가 있어도 내용어 75% 이상 일치(63개), 핵심어 없는 사실은 내용어 60% 이상 일치(10개)
   - 핵심어 자체의 항목에 개념 이름이 나오거나 시대·내용이 일치(48개)
   - 다른 항목에서 핵심어와 개념 이름이 가까이 나오는 경우는 **우연 일치가 많아(표본 25개 중 약 9개) 확인으로 치지 않고** 사람 검토 후보로만 씀
4. **문장 근처 일치 등급**(`scripts/verify_strength.py`): 위 3에서 확인된 사실마다, 핵심어가 있는 문장(앞뒤 한 문장 포함) 안에 사실의 나머지 내용어가 절반 이상 함께 있는지 봄(핵심어 없는 사실은 60% 이상, 핵심어 항목으로 확인한 사실은 그 문장 근처에 개념 이름도 있어야 함).
   - 있으면 **강한 자동 확인**(앱의 ‘자동 확인’), 없으면 **약한 자동 확인**(핵심어만 맞음) → 약한 것은 **사람이 출처를 읽기 전에는 확인으로 치지 않음**.
5. 사람 확인: 근거(백과사전 Article ID 또는 우리역사넷 문서 ID)와 요지를 `scripts/verify-manual.json`에 기록. 관련 항목 목록·참고문헌만으로는 인정하지 않음.
   - 자동 대조에서 근거를 못 찾은 사실 **165개**(`facts`)
   - 약한 자동 확인 **279개 전부**와 강한 자동 확인 표본에서 세부가 다른 곳에 있던 4개(`reviewed`, 아래 ‘약한 자동 확인 검토’)
   - 남은 강한 자동 확인 **574개 전부**(`reviewed`, 아래 ‘강한 자동 확인 전수 읽기’) → 이로써 사실 1,022개 모두 사람이 근거 문장을 읽음
   - 우리역사넷은 스크립트 접속을 막아(검색 404) 앱 내장 브라우저에서 같은 사이트 검색을 돌려 본문을 읽음. 역대 국사교과서는 검색 목록에 차수가 나오지만 문서 페이지에서 일관되게 확인하기 어려워 ‘역대 국사교과서(고등학교/중학교 국사)’로만 표기.
6. `scripts/verify_build.py`가 결과를 `src/content/verification.json`으로 합침. 사실 상태는 사람 확인 > 강한 자동 확인 > 미확인 순. **모든 사실 + 표시 연대가 확인된 개념만 ‘대조 완료’**, 하나라도 남으면 ‘일부 확인’.

- **자동 확인의 의미와 한계**: 앱의 ‘자동 확인’은 “핵심어와 사실의 나머지 내용이 그 항목 본문의 같은 문장 근처에 함께 있다”는 뜻(사람이 문장의 뜻을 읽은 것은 아님). 강한 자동 확인 무작위 표본 30개를 사람이 읽어 보니 30개 모두 출처가 사실을 뒷받침했고, 26개는 일치한 문장 자체에서, 4개는 같은 항목의 다른 문장이나 우리역사넷에서 세부(남만주·국민당 정부 지원·함경도 관찰사 조병식·반량전)를 확인 → 이 4개도 사람 확인으로 기록. 1글자 핵심어(왜·철·얼 등)는 다른 낱말 속에서 잡혀 근거로 쓰지 않음.
- **약한 자동 확인 검토(279개, 2026-11-27)**: 같은 개념 항목 본문에서 문장 내용까지 확인 217 · 다른 백과사전 항목(핵심어 항목 등)에서 확인 48 · 우리역사넷에서 확인 13 · 문장을 고친 뒤 같은 항목에서 확인 1.
  - **엉뚱한 항목과 일치했던 것 3개**를 찾아 근거를 바꿈: ‘송상’이 인물 송상현 항목에서, ‘향전’이 모기향(香篆) 항목에서, 정상기의 「동국지도」가 1463년 정척·양성지의 같은 이름 지도 항목에서 잡혀 있었음 → 「개성상인」·「향전(鄕戰)」·정상기 「동국지도」로 교체(동국지도는 `verify-queries.json`에 ‘동국지도|정상기’ 조건 추가).
  - 출처에서 세부를 찾지 못해 **문장을 고친 것 3개**: 권문세족 ‘친원 세력인’ 수식 삭제(백과사전 「권문세족」은 원의 행성 설치에 반대해 부원 세력과 구별된다고 서술) → ‘원 간섭기에 새로운 지배 세력으로 등장’ / 민정 문서 ‘촌주가 3년마다 작성’ → ‘변동 사항을 조사해 3년마다 다시 작성’(작성 주체는 확인 못함) / 덩이쇠 ‘화폐처럼 사용’ → ‘사용하기도’(용도는 철 소재설·화폐설).
  - 새 메모 8곳(개념 화면·CURRICULUM.md 7절): 광해군 ‘중립 외교’ 평가에 대한 이견, 조선의 속현 정리(17세기경 완료), 고인돌을 지배층 무덤으로 보는 것은 교과서 서술, 덩이쇠 용도, 고이왕 27~29년 기사의 성격(중국 측 기록을 옮긴 것으로 보는 이해), 문왕과 신라도(두 출처를 합친 판단), 권문세족, 민정 문서 작성 주체.

## 2-2. 문제·설명문 점검과 사료 원문 링크(2026-11-27)

### 오답 재료 점검(`npx tsx scripts/audit-questions.ts`, 테스트 `tests/audit.test.ts`)
문제는 다른 개념의 사실을 오답 선택지(‘옳은 것은?’의 오답, OX의 거짓 문장, ‘옳지 않은 것은?’의 정답)와 ‘누구인가’ 문제의 오답 후보로 씁니다. 그 사실이 실제로는 대상에도 맞으면 정답이 둘이 됩니다.
- 자동 점검: 같은 종류의 모든 개념 쌍에서, 다른 개념의 사실 문장에 대상의 이름이 들어 있거나, 사실의 핵심어와 나머지 내용어 절반 이상이 대상의 사실·설명문 한 문장에 함께 나오는 조합을 찾음 → **73건**.
- 사람 판단(`src/content/overlaps.ts`): 대상에도 맞거나 맞는다고 볼 여지가 있는 **19건은 예외 목록**(예: 지청천 총사령관 → 한국 광복군도 해당, 수원 화성 축조 → 정약용, 유네스코 기록 유산 → 4·19 혁명 기록물도 2023년 등재, 신문고 설치 → 영조가 다시 설치), 대상 이름이 문장에 있는 **17건은 이름 규칙**으로 자동 제외, **37건은 대상에는 분명히 틀린 설명**(기출의 대표적 구별 포인트: 최우의 정방 → 최충헌, 의천↔지눌 등)으로 확인해 그대로 씀. 새 콘텐츠가 점검에 걸리면 테스트가 실패해 다시 판단하게 함.
- 같은 내용인데 비교 키가 달랐던 사실 1쌍을 합침(고국천왕·근초고왕 ‘왕위의 부자 상속’).
- 생성 문제 표본 **104개**(13개 유형 × 4문항 × 2회)를 사람이 읽고 고친 결함: ① ‘누구’ 문제 자료에 정답 이름이 드러남(‘보안회와 대한 자강회’ ← ‘보안회가…’) → 이름의 구성 부분까지 검사 ② ‘1920년대’를 1920년으로 읽은 연도 문제 ③ 기간이 겹치는 개념끼리 순서 문제(‘1860~1890년대’ 위정척사 운동 등) → 시기 범위가 겹치지 않는 것만 ④ 하나의 자료가 두 개념에 맞음(제주 4·3·여순 사건의 민간인 희생) → 예외 목록의 사실·일반적 서술은 자료로 쓰지 않음 ⑤ 빈칸 오답이 정답을 품음(사비/사비성, 향약/예안 향약) ⑥ 정답 선택지에 대상 이름이 그대로 있어 너무 쉬움, 이름에 ‘~와 ~’가 든 개념의 비교 문제 발문.
- 한계: 자동 점검은 대상 개념의 사실·설명문에 나오는 겹침만 찾음. 앱 설명에 없는 ‘사실상 맞는 오답’은 놓칠 수 있음.

### 설명문 점검
- 설명문 **983문장**에서 커리큘럼의 고유어(개념 이름·별칭·빈칸어, 『』·「」 안 이름)와 연도·숫자를 뽑아, 그 개념의 확인된 사실이나 출처 항목 본문에 있는지 봄 → 803문장은 모두 있음, **180문장**은 하나 이상 없음.
- 180문장을 사람이 읽음 → 틀린 서술 없음(대부분 다른 개념의 고유어·연도를 언급한 것: 나제 동맹 433, 9서당 10정, 상정고금예문 1234, 창씨개명 1940 등).
- 한계: 문장 전체의 의미(관계·인과)를 출처와 하나하나 대조한 것은 아님.

### 사료 원문 링크(`src/content/primarySources.ts`)
- 자료(사료 요지)가 있는 개념 등 **16개 개념**에 공식 데이터베이스의 해당 기사 링크: 조선왕조실록 6(훈민정음 서문, 강화도 조약, 헌의 6조, 대한국 국제, 을사늑약, 기사환국 송시열 상소), 한국사데이터베이스 8건·9개 개념(삼국유사 고조선, 삼국사기 법흥왕 이차돈, 고려사 대목왕후·최승로 시무 28조·서희·최충헌 봉사·만적·신돈), 국가법령정보센터 1(유신 헌법). 링크마다 직접 열어 기사 제목·본문이 자료 요지와 맞는지 확인.
- 실록 국역(세종대왕기념사업회)·한국사데이터베이스 번역문(국사편찬위원회)은 저작물이므로 앱에 옮겨 싣지 않고 링크만 연결.
- 공식 원문 링크를 찾지 못한 자료(갑신정변 14개조 정강, 조선 혁명 선언, 신간회 강령, 동학 농민군 격문, 영조 탕평 교서 등)는 요지만 있음.
