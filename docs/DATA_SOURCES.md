## 2. 기출문제 확보·분석(제57~80회 심화)

### 확보
- 2026-11-26, 사용자 허락을 받고 공식 자료실에서 **48개 PDF**(24개 회차 × 문제지·정답표, 약 332MB)를 내려받음. 파일은 `exam-pdfs/`에 있으며 **git과 앱 배포본에 포함하지 않음**(`.gitignore`).
- 재현: `scripts/download-ids.txt`(공식 첨부파일 ID) → `scripts/extract-text.mjs`(PDF 글자) / `scripts/ocr-pdf.ps1`(Windows 한국어 OCR) → `npx tsx scripts/analyze-exams.ts`.

### 글자 추출
| 회차 | 방법 |
|---|---|
| 58, 62, 70, 71, 72, 75, 76, 77, 80 (9개) | PDF 글자 레이어(pdf.js), 2단 편집 순서로 재정렬 |
| 57, 59, 60, 61, 63, 64, 65, 66, 67, 68, 69, 73, 74, 78, 79 (15개) | 글자 레이어가 없는 이미지 PDF → Windows 내장 OCR(한국어), 2단 순서로 정렬 |
| 정답표 24개 | 모두 글자 레이어. 형식 2가지(①~⑤ / 숫자) + 63회 42번 “없음”(정정, 전원 정답) |

### 분석 방법(자동)
1. 정답표 → 문항별 정답·배점(24개 회차 모두 50문항·합계 100점 검증 통과).
2. 문제지 → 문항 번호로 50개 문항 분할 → 발문·자료·선택지 분리.
3. 앱 개념 사전(개념 이름·핵심어·빈칸어)의 키워드를 **IDF 가중치**로 매칭. 자료 1.6배, 정답 선택지 1.4배, 나머지 선택지 0.35배. 문항 위치(대체로 시대순)와 문항 유형(‘지역’ 문항은 지역 개념 우대)을 약하게 반영.
4. 점수가 낮으면 태그를 붙이지 않음(추측 금지).
5. 집계: 개념별 “관련 문항이 나온 회차 수”(주 개념·관련 개념·정답 선택지 개념 포함), 단원별 주 개념 문항 수.

## 2-1. 개념 콘텐츠 대조(2026-11-27)

AI가 쓴 302개 개념(사실 1,022개)을 한국학중앙연구원 「한국민족문화대백과사전」 항목 **본문 서술**과 대조하고, 백과사전에서 근거를 찾지 못한 서술은 국사편찬위원회 **우리역사넷**(신편 한국사·역대 국사교과서·사료로 본 한국사·한국문화사)으로 확인했습니다.

### 방법
1. 개념마다 백과사전 검색(`/Article/Search?query=…`)으로 해당 항목을 고름(제목 일치 + 시대·키워드 조건, 개념별 검색어는 `scripts/verify-queries.json`). 항목 글자는 `verify-cache/`에만 저장(git·앱 배포본 제외).
   - 잘못 고른 항목 1건을 찾아 고침: ‘선종의 확산’이 고려 국왕 **선종** 항목에 연결돼 있었음 → 「선종구산문」·「불립문자」·「도의」로 교체. 비슷한 실수(왕 항목이 다른 개념에 붙음)가 더 있는지 302개 전부 훑어봄 — 나머지 12건은 왕 이름이 들어 있을 뿐 맞는 항목.
2. **본문 서술만** 사용: 항목 페이지의 관련 항목 목록·사진 설명·키워드 목록·참고문헌·주석은 뺌. (처음에는 페이지 전체를 썼는데, 참고문헌 책 제목 ‘서경문화사’가 ‘서경’으로, ‘초기철기시대’가 ‘철’로 잡히는 등 잘못된 확인이 표본에서 나와 고침.) 연대는 본문 + 정보 상자(출생·사망·재위 연도)에서 찾음.
3. 사실별 자동 확인(`scripts/verify_check.py`)
   - 핵심어(빈칸어, 2글자 이상)가 그 개념 항목 본문에 있음 → **자동 확인**(738개)
   - 핵심어 표기 차이(숫자 표기 등)가 있어도 내용어 75% 이상 일치(63개), 핵심어 없는 사실은 내용어 60% 이상 일치(10개)
   - 핵심어 자체의 항목에 개념 이름이 나오거나 시대·내용이 일치(48개)
   - 다른 항목에서 핵심어와 개념 이름이 가까이 나오는 경우는 **우연 일치가 많아(표본 25개 중 약 9개) 확인으로 치지 않고** 사람 검토 후보로만 씀
4. **문장 근처 일치 등급**(`scripts/verify_strength.py`): 위 3에서 확인된 사실마다, 핵심어가 있는 문장(앞뒤 한 문장 포함) 안에 사실의 나머지 내용어가 절반 이상 함께 있는지 봄(핵심어 없는 사실은 60% 이상, 핵심어 항목으로 확인한 사실은 그 문장 근처에 개념 이름도 있어야 함).
   - 있으면 **강한 자동 확인**(앱의 ‘자동 확인’), 없으면 **약한 자동 확인**(핵심어만 맞음) → 약한 것은 **사람이 출처를 읽기 전에는 확인으로 치지 않음**.
5. 사람 확인: 근거(백과사전 Article ID 또는 우리역사넷 문서 ID)와 요지를 `scripts/verify-manual.json`에 기록. 관련 항목 목록·참고문헌만으로는 인정하지 않음.
   - 자동 대조에서 근거를 못 찾은 사실 **165개**(`facts`)
   - 약한 자동 확인 **279개 전부**와 강한 자동 확인 표본에서 세부가 다른 곳에 있던 4개(`reviewed`, 아래 ‘약한 자동 확인 검토’)
   - 우리역사넷은 스크립트 접속을 막아(검색 404) 앱 내장 브라우저에서 같은 사이트 검색을 돌려 본문을 읽음. 역대 국사교과서는 검색 목록에 차수가 나오지만 문서 페이지에서 일관되게 확인하기 어려워 ‘역대 국사교과서(고등학교/중학교 국사)’로만 표기.
6. `scripts/verify_build.py`가 결과를 `src/content/verification.json`으로 합침. 사실 상태는 사람 확인 > 강한 자동 확인 > 미확인 순. **모든 사실 + 표시 연대가 확인된 개념만 ‘대조 완료’**, 하나라도 남으면 ‘일부 확인’.

## 4. 미확보 자료 · 미완료 작업

1. **2022년 이전 기출(최근 10개년 중 약 6년치)** — 공식 자료실에 없음(제56회 이하·구 고급).
2. **기출 분석의 사람 전수 검수** — 표본 2개 회차만 검수. 개념 단위 태그는 일부 틀릴 수 있음.
3. **문항별 체감 난이도·선행 지식·문항 간 연관성** — 분석하지 않음.
4. **콘텐츠 검증** — 사실 1,022개 모두 출처 대조 완료, 약한 자동 확인 279개는 모두 사람이 읽음(2-1절). 남은 일: 강한 자동 확인 574개의 사람 전수 읽기(표본 30개는 모두 맞았으나 4개는 세부가 다른 문장에 있었음), 문제 문장·오답 선택지·설명문 전수 검수, 현행 검정 교과서와의 대조.
5. **문화재 이미지 맞히기 · 지도 기반 문제** — 미구현(이미지·지도 자료와 이용조건 미확보).
6. **사료 원문** — 원문 대신 요지를 풀어 쓴 자료만 사용(정확성·저작권 이유).
7. **기출에는 나오지만 앱 개념에 없는 주제** — 예: 고려 은입사 공예, 일제 강점기 대중문화(경평 축구), 조선 후기 중인 시사(옥계시사) 등. 분석에서 태그 보류된 문항을 보고 개념을 추가할 필요가 있음.
